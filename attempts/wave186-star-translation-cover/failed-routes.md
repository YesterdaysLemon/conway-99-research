# Wave 186 boundaries

## The outside circuits may overlap heavily

The count deliberately allows one forced outside circuit to serve three
private labels.  Treating every translate as globally new would overstate
the result.

## Private labels, not every label

A translated circuit is known to lie outside the selected cover only for a
private label.  Translates attached to nonprivate labels may already be
selected elsewhere.  The inequality uses the exact lower bound on the number
of private labels rather than assuming the cover is a partition.

## No complete-enumerator contradiction

The new bound `B_4+...+B_9>=8778` has no currently proved incompatible upper
bound for every surviving complete enumerator.  Raw circuit abundance alone
does not exclude a rank-11 ternary matroid.

## The former root geometry is now a vacuous branch

Waves 182--185 remain correct conditional deductions from `Q=2079`, but
Wave 186 excludes that antecedent.  Their local root objects should not be
treated as necessary for a general endpoint model with `Q>=3696`.
