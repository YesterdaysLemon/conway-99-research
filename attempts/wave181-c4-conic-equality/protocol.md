# Protocol

1. Freeze the verified centered Gram table, dual-distance theorem, exact
   two-transversal classification, and Wave 180 companion theorem.
2. In the shared-center case, count the baseline edge `xt` in every disjoint
   outer-star cross-edge total.  Do not replace `j` by `j-1`.
3. Use `P=0` before separating the two extra common neighbors into distinct
   star blocks.
4. Apply the Wave 180 classification only after proving that `x` is
   anticomplete to the leaf triangle.
5. Recover the canonical nonedge involution directly from `mu=2` and
   `lambda=1`.
6. Distinguish the four-column Gram kernel from a true relation; promote the
   checkerboard word only for a circuit already assumed to exist.
7. Prove equality in the cover bound before asserting that all 2,079
   canonical quadrilaterals are circuits.
8. Record the signed incidence matrix and projector sum as continuation
   boundaries, not rank or endpoint contradictions.
9. Perform no graph, code, SAT, configuration, or isomorphism search.
10. Require independent verification before promotion.
