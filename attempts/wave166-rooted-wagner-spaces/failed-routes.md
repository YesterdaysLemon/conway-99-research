# Failed routes and the exact remaining lemma

## Fixed-C4 degrees do not force a Wagner

The `Z/9` shift shell satisfies every currently derived boundary and
opposite-class degree equation but has no crossed Wagner pattern. Any proof
using only those equations is impossible.

## Uniform five extensions per C5 is stronger than necessary

The clean local target `e_W(F)>=5` would give `W8>=20790`, but no local
argument currently forces it. The exact aggregate target is only 149,680
extensions.

## Pair equations stop at eight possible failures per nonedge

For either common-neighbor lane of a fixed nonedge, at most four marked
cycles have visibly impure forced endpoints. Proving that every remaining
pure cycle extends would still allow four failures in each lane. The desired
bound is four total, so a cross-lane compatibility theorem is indispensable.

## Pair-root order eight plus the new scalar bounds still survives

The verified Wave 150 pseudowitness has `C8=11781/4`, `W8=35343/2`, and
slack 2,079 in both endpoint scalar inequalities. It also lies on the
pair-root centered PSD face. Hence that exact finite relaxation cannot prove
`W8>=18710`.

The next conic experiment must include the whole root-3 and root-12 blocks,
not only their sampled cuts. If that system also survives, completion second
moments naturally require order eleven unless a uniqueness/overlap lemma
lowers the union order.

## First unproved lemma

```text
In the prism-free branch, every nonedge has at most four failed marked
induced-C5 Wagner extensions among its exact forty.
```

No proof is claimed.
