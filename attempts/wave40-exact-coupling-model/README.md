# Wave 40 exact three-fibre rank coupling

Status: **CANDIDATE pending clean-room verification**.

This package strengthens the Wave 39 characteristic-seven argument by
coupling every edge-local normal form to all twelve vertices in the third
fibre of the edge's triangle mate. The exact candidate theorem is

```text
Every hypothetical srg(99,14,1,2) has rank_F7(M) >= 25,
where M=21E_0 is the integral triangle projector.
```

The previous independently verified floor is `19`. This discovery cannot
promote its own result.

## 1. The three fibres

Fix an edge `xy`, let `z` be its unique common neighbour, and put

```text
X=N(x)-{y,z},
Y=N(y)-{x,z},
Z=N(z)-{x,y}.
```

Each fibre has twelve vertices and induces a perfect matching. The relations
between every two fibres are also perfect matchings. For example, if `c` is
in `Z`, then `c` and `x` are nonadjacent. They already have common neighbour
`z`, so `mu=2` gives exactly one further common neighbour of `c` in `X`.
Counting both sides makes the `X-Z` relation a perfect matching. The same
argument applies to `Y-Z`.

Relabel `X` so its internal matching is the standard matching, and pull the
labels of `Y` through the `X-Y` matching. This leaves an arbitrary perfect
matching on twelve labelled points. The program exhausts all

```text
11!! = 10,395
```

choices and recovers the eleven positive partitions of six from Wave 39.
This is a local relabelling, not an automorphism assumption on a completed
graph.

The partition is a complete invariant for this labelled reduction. Given two
pulled-back matchings with the same partition, pair their equal-length
alternating components and map each alternating `X-matching/Y-matching`
traversal to the other. The resulting permutation centralizes the standard
`X` matching and conjugates one pulled-back `Y` matching to the other. The
checker explicitly constructs and validates such a conjugator for all 10,395
labelled matchings before retaining one representative of each type.

Now index `Z` through the `X-Z` perfect matching. Its `Y` neighbours have
indices

```text
(0,f(0)),...,(11,f(11))
```

for an arbitrary permutation `f`. Thus the complete third-fibre attachment
has `12!` possibilities at this stage.

## 2. Rank-congruence lemma

Let `S` be the 27 by 27 Seidel block `J-I-2A` on

```text
{x,y,z} union X union Y.
```

Let `U` contain the twelve Seidel columns from `Z`, let `W` be the
`Z-Z` block, and let the columns of `K` form a basis of `ker(S)`. Over any
field,

```text
rank [ S    U ] >= rank(S) + 2 rank(K^T U).
     [ U^T  W ]
```

To prove this, apply an invertible congruence taking `S` to
`diag(D,0)` with `D` nonsingular. Eliminate the part of `U` alongside `D`.
The remaining block has the form

```text
[ 0    U0 ]
[ U0^T W' ],
```

where `rank(U0)=rank(K^T U)`. Row and column basis changes expose that many
independent hyperbolic pairs, contributing at least twice `rank(U0)`.
Crucially, the unknown block `W` cannot lower this bound.

## 3. Exact permutation census

For one partition `pi`, the program:

1. constructs the canonical 27-point block `S_pi`;
2. computes an exact basis of `ker(S_pi)` over `F_7`;
3. computes all 144 projected signature vectors
   `K^T u_(i,j)`;
4. enumerates every subspace spanned by the observed projective lines; and
5. asks whether its supported signature positions contain a perfect
   bipartite matching.

A perfect matching is exactly a permutation `f`. Every minimum span is
generated by its selected observed vectors, so the subspace enumeration omits
no possible smaller span. This replaces a direct traversal of `12!`
permutations with an exact finite matching certificate.

The result is:

| partition `pi` | `rank(S_pi)` | minimum `rank(K^T U_f)` | coupled floor |
| --- | ---: | ---: | ---: |
| `1+1+1+1+1+1` | 25 | 0 | 25 |
| `1+1+1+1+2` | 23 | 1 | 25 |
| `1+1+1+3` | 25 | 0 | 25 |
| `1+1+2+2` | 21 | 2 | 25 |
| `1+1+4` | 23 | 1 | 25 |
| `1+2+3` | 23 | 1 | 25 |
| `1+5` | 25 | 0 | 25 |

| `2+4` | 21 | 2 | 25 |

The hardest type is `2+2+2`. Its observed projections give 66 projective
lines. The complete lower-dimensional census is:

```text
dimension 0:      1 subspace, maximum supported matching 0
dimension 1:     66 subspaces, maximum supported matching 4
dimension 2:  1,923 subspaces, maximum supported matching 8
dimension 3: 25,744 subspaces, first supported matching 12
```

Every type satisfies

```text
rank(S_pi) + 2*minimum_projection_rank = 25.
```

The machine-readable `subspace-certificate.json` retains every rejected
subspace below the first successful dimension and a positive permutation
witness at the boundary for every type.

## 4. Consequences and strict boundary

Using the independently verified transport

```text
rank_F7(M)=rank_F7(N M N^T),
N M N^T = 27I-9A+J = J-I-2A mod 7,
```

the 39-point principal block gives the candidate universal floor

```text
rank_F7(M) >= 25.
```

At the conditional prism-free endpoint, combining this with the previously
verified ranges and parity leaves 330 arithmetic `(r3,r7)` pairs rather than
429. If `r3=12`, then `r7` is even and at least 26.

This does **not** exclude `n3=4158`, improve the general upper bound, construct
a graph, or resolve Conway-99. Those statuses remain `UNKNOWN`.

## 5. Fully specified 39-block scout

The proof allows the `Z-Z` block `W` to be arbitrary because that is enough
for the rank-25 lower bound. In an actual graph, `Z` induces six disjoint
matching edges. `full_block_scout.py` restores that matching and samples 512
deterministic `(Y-Z permutation, Z matching)` pairs for each edge type.

For every fully specified three-fibre block, exact block reduction gives

```text
rank_F7(K_39) = 1 + rank_F7(3I_36-A_core).
```

The 36-space splits into the three-dimensional fibre-constant space and the
kernel of fibre incidence. The cubic core has equitable quotient `J_3`. On
the incidence kernel, `K_39` is twice `3I-A_core`; on the remaining six
triangle/fibre-constant coordinates the two ranks are respectively three and
two.

There is an exact aligned positive control: partition `1+1+1+1+1+1`,
identity `Y-Z` permutation, and the standard matching in `Z`. Its cubic core
has six components of size six and

```text
rank_F7(3I-A_core)=30,
rank_F7(K_39)=31.
```

It contains type-1/prism structure and is not an endpoint control. The 512
random samples per type have ranks 34--36. The sample is not an exhaustive
quotient of the `12!*10,395` possibilities, and its minima are not stronger
rank bounds.
