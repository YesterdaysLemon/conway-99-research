# Failed routes and retained boundaries

## Integral WL parameters

Every expanded object is a realized finite incidence template. Its stable
2-WL intersection numbers are therefore nonnegative integers. No relation
type is excluded at this level. This is a null result, not evidence that a
putative Conway graph exists.

## Exact 3-WL on the triangle core

Exact 3-WL refines the genuinely two-root typed cores but cannot see the
exact-two right side of cap nodes, because the cap nodes are deliberately
omitted from the smallest tractable triple lift. It gives no contradiction.

## Positive cap controls

All four root relations admit deterministic local 2-factor controls. These
controls satisfy the merged cap equations, including the single shared
forced-true variable in relation `B`. They do not assign the remaining 231
triangle relations and are not graph constructions.

## Why no completion closure is reported

Selecting any full set of `B/C` values before WL would reintroduce the Wave 52
completion-dependence problem. The controls are used only to prove local
feasibility and are never supplied to either WL computation.
