# Wave 112 retained boundary

## Average versus pointwise multiplicity

The modular lower bound proves that some four-cycle has at least 26
antipodal short-support extensions. It does not bound any cycle from above.
An average count is not a contradiction.

## Fixed-cycle partition

The exact `51,20,20,4` anchor partition sharply reduces the local domain,
but it does not determine edges among the 95 outside vertices. Counting
candidate subsets without enforcing all target codegrees would not prove
the desired cap.

## Solver boundary

A proof-producing formulation should ask whether 26 distinct antipodal
short supports can coexist around one normalized cycle. An uncertified
solver `UNSAT`, a timeout, or a search restricted by an unproved
automorphism would not establish the cap.
