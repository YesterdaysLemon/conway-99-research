# Wave 112 protocol

## Frozen scope

Conditional on the verified rank-28 short-vector reduction, count induced
four-cycles in each allowed signed support and reduce the global shell lower
bound to a local extension-multiplicity target around one normalized
four-cycle.

No automorphism of the unknown target is assumed. Normalizing one cycle is
ordinary relabelling.

## Gates

1. Reconstruct the target four-cycle count from `lambda=1,mu=2`.
2. Count only cycles forced by the sign-side cross graph.
3. Preserve separate norm-18 `h=0,1` branches.
4. Count oriented vectors and apply antipodal parity explicitly.
5. State a local cap only as a sufficient future target until proved.
6. Do not promote the reduction to a rank exclusion or graph result.
