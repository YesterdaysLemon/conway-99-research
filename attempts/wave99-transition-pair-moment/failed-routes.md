# Wave 99 retained boundary

The pair-moment argument improves only the norm-14 shell. The formal
`n4=42,n3=168,n0=350` seed distribution saturates the two scalar moments,
so those moments alone cannot improve `N14<=4950`.

Closing the endpoint rank-28 row now requires at least one of:

- a stronger transition compatibility inequality;
- a graph-specific upper bound on `N16` or `N18`;
- incompatibility of the Wave 81 norm-16 labelled designs with the rooted
  transition matchings; or
- a higher-order lattice or code constraint coupling the three shells.

The weighted inequality is not itself an upper bound or contradiction.
