# Protocol

## Scope

Translate the prism-free Conway-99 endpoint into the incidence geometry of
its unique edge-triangles and identify an exact higher-order invariant that
distinguishes cube and Wagner motifs.

## Required checks

1. Count blocks and point degrees without assuming automorphisms.
2. Derive every matrix identity from incidence definitions.
3. Audit all eigenvalue multiplicities and kernel dimensions.
4. Prove both directions of the prism/block-codegree correspondence.
5. Check the cube and Wagner determinants exactly.
6. Derive the global minor-energy identity by Cauchy-Binet.
7. Treat the neighborhood-triple code as a consistency object, not a
   contradiction.
8. Keep the proposed minor classification explicitly `UNPROVED`.

## Computation boundary

This wave is paper-only because host free memory was below the user's floor.
Any later enumeration must start only with at least 18 percent free memory,
stop before 15 percent, emit complete manifests, and receive an independent
semantic verifier.
