## 2. The complete outside pattern universe

Let `w` be one of the 72 vertices outside `L`, and put
`a_z=1` when `w` is adjacent to `z`. The definition of `L` makes `w`
nonadjacent to both `x` and `y`. Applying `mu=2` to `(w,x)` and `(w,y)`
gives the exact equations

```text
a_z + |N(w) intersect X| = 2,
a_z + |N(w) intersect Y| = 2.
```

Consequently the complete binary pattern universe has

```text
a_z=1: 12*12 = 144 patterns,
a_z=0: binom(12,2)^2 = 4,356 patterns.
```

No automorphism of the full graph is assumed. A further visible
`lambda=1` cap removes 240 of the `a_z=0` controls, leaving 4,116, but the
rank proof deliberately uses the larger complete universe.

The restricted `K` column is the affine vector

```text
K[L,w]=1-2 A[L,w],
```

so its entries are `1` on nonedges and `-1=6` on edges. It is not the
zero-one adjacency column.

Finally,

```text
Z=N(z)-{x,y}
```

consists of twelve outside vertices. The nonedge `uz`, for each `u in X`,
has common neighbor `x` and exactly one more common neighbor in `Z`.
The analogous statement holds for `Y`. Therefore the twelve `Z` patterns
form a perfect matching from `X` to `Y`.

## 3. Rank-completion quotient

Block `K` as

```text
K = [ B  C   ]
    [ C^T D  ].
```

The column space of `[B C]` is the restriction to `L` of the full column
space of `K`. Hence, if it is denoted by `R`,

```text
col(B) subseteq R,
dim(R) <= rank(K),
dim(R/col(B)) <= rank(K)-rank(B).                (1)
```

In particular, equality `rank(K)=rank(B)` forces every outside restricted
column into `col(B)`.

Because `B` is symmetric,

```text
col(B)=ker(B)^perp.
```

Dotting a column with a basis of `ker(B)` therefore gives exact coordinates
for its class modulo `col(B)`. These are the quotient syndromes used below.

## 4. Exact case analysis

### Rank 19

Only edge type `2+2+2` can occur. Its local block has rank 19 and nullity
eight. Exhausting all `144+4,356=4,500` affine columns finds exactly 36 in
`col(B)`, all with `a_z=0`. None of the 144 required `Z` columns is in
`col(B)`, contradicting (1).

### Rank 20

Again every edge has type `2+2+2`. The quotient images of all outside
columns now span at most a line. The 144 possible `Z` columns occupy 66
projective syndrome lines:

```text
60 lines contain 2 patterns,
 6 lines contain 4 patterns.
```

One line can contain at most four of the twelve distinct forced `Z`
patterns, a contradiction.

### Rank 21

Only types `2+2+2` and `2+4` can occur.

- If a `2+4` edge exists, its local rank is already 21. Exact elimination
  finds none of its 144 possible `Z` columns in `col(B)`, contradicting the
  equality case of (1).
- Otherwise every edge has type `2+2+2`. The twelve `Z` syndromes must span
  at most a two-space. There are 66 observed projective lines and exactly
  1,923 distinct two-spaces generated by their pairs. Exact enumeration
  gives maximum matching number eight:

  ```text
  matching number 2:  480 spaces
  matching number 4: 1,251 spaces
  matching number 6:  168 spaces
  matching number 8:   24 spaces
  ```

  None contains the required perfect matching of size twelve.

This exhausts `r7<=21` and yields the candidate floor 22.
