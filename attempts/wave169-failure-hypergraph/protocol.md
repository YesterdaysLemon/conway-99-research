# Protocol

## Scope

Test whether pairwise incompatibility among the 40 nonedge-rooted marks can
prove the pointwise four-failure target, and formulate the first stronger
space when it cannot.

## Checks

1. Preserve the exact 40-mark and eight-per-Wagner multiplicities.
2. Distinguish the four mandatory fringe failures from conditional inherited
   core failures.
3. Saturate the middle neighborhood as exactly seven disjoint edges.
4. Audit every common-neighbor assignment used by the five-mark gadget.
5. Treat unspecified global SRG closures as missing, not silently satisfiable.
6. Infer only insufficiency of the currently encoded local clauses.
7. Keep the global `E<=8` target separate from the stronger pointwise target.

## Computation boundary

The analysis is paper-only. No process may start below 18 percent free host
memory or continue below 15 percent. Any later SOS or hypergraph computation
must emit an exact certificate and receive an independent verifier.
