# Wave 109 failure boundary

Claim label: `UNKNOWN` for all conclusions beyond the exact conditional
reduction.

## No Witt obstruction

The characteristic-seven image of `B=D+4I` is totally isotropic, but the
ambient kernel lattice reduces to `O^-(74,7)`, whose Witt index is 36. The
imported local ranks are only `16,18,...,30`, so the sharp dimension bound
does not exclude a row.

## The sign does not strengthen the current rows

The determinant square class is informative enough to correct the ambient
type from a possible mistaken `O^+` to `O^-`. After removing a totally
isotropic `k`-space, however, the residual space is simply
`O^-(74-2k,7)` in every row. This is compatible with all eight ranks.

## Smith data are conditional, not realizations

The Smith pattern

```text
1^k, 7^(42-k), 0^32
```

and the two index formulas follow from `B^2=7B`; they do not construct an
integral matrix `D` satisfying all adjacency and common-neighbor equations.

## No use of the linear witness as a graph

Wave 105 exhibited a matrix satisfying only degree and incidence-block
equations. It failed the full SRG equations. Treating it as the unknown `D`
would invalidate the projector identity, so it is deliberately excluded
from this calculation.

No motif exclusion, full graph construction, Conway-99 resolution, or
literature-novelty claim is made.
