# Failed and boundary routes

## Counting only multiplicity-five labels

Wave200 used only fully saturated labels. That discards repetition from
multiplicities two, three, and four. The weighted row charges all of them.

## Subtracting a baseline from every fiber

Only the three Hilton--Milner degree-five pair types at a 13-flag center
have an unavoidable one-unit repeat. Subtracting from other fibers is
unjustified and is not used.

## Multiple selected labels in one fiber

One cannot assign the same repeated occurrence to two leaf values.
Writing the full repetition as `sum_z(r_z-1)` separates leaf values and
proves the charges additive.

## Negative eta coefficient

The derived global row contains `-3eta`. It is not treated as a
nonnegative term. The subsequent exact budget subtraction contributes
`+8eta`, so the final domination remains a sum of nonnegative quantities.

## Search

No finite configuration search was run. The result is a symbolic
multiset/incidence theorem.
