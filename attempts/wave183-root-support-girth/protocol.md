# Protocol

1. Work only under the independently verified Wave 182 setting and retain
   Wave 181 equality `Q=2079` explicitly.
2. Use exact nonedge root uniqueness before identifying the label of an
   opposite nonedge.
3. Use canonical-C4 root orthogonality only after proving that both opposite
   endpoints lie in the same root support.
4. Count internal two-paths as unordered endpoint pairs and use the
   at-most-one common-neighbor conclusion; do not enumerate graphs.
5. In the cubic eight-point case, distinguish adjacent and nonadjacent
   endpoint pairs and use `lambda=1` to make triangles edge-disjoint.
6. Classify only the elementary degree-zero, degree-one, and 2-regular
   survivors; make no automorphism assumption.
7. Count projective roots, not their two nonzero vector representatives.
8. Preserve the conditional scope: this narrows the Wave 181 equality face
   but does not exclude it.
9. Treat the split frame identity as a target, not as a contradiction.
10. Perform no graph, code, SAT, configuration, or isomorphism search.
11. Require independent verification before promotion.
