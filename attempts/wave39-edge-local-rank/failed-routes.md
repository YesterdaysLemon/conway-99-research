# Wave 39 edge-local rank boundary

The exact 27-vertex transport block improves the characteristic-seven rank
floor but does not exclude the prism-free endpoint.

The weakest endpoint normal form is

```text
partition 2+2+2,
rank_F7 local block = 19.
```

Consequently the argument cannot by itself force `rank_F7(M)>=45`, which
would contradict the rational rank 44. It also cannot exclude the surviving
pair `(r3,r7)=(12,20)`.

Any continuation from this lane must use information coupling distinct
edges. Examples include:

- prove that not every edge can have type `2+2+2`;
- combine overlapping 27-vertex blocks to force additional independent
  rows modulo seven;
- show that the low-rank local partitions conflict with the simultaneous
  one-triangle `B/H` equations.

No such coupling theorem is proved here. The endpoint, the bound
`n3<=4158`, Conway-99, and novelty remain `UNKNOWN`.
