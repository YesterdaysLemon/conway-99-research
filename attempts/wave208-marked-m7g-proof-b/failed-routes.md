# Failed routes and quarantined computations

## Phillips `tau,rho` marginals do not see the obstruction

The unmarked triangle-clique-graph equations constrain one selected row at a
time.  They do not retain the signed sum `S_D` or the coordinatewise factor
three in `(A-3I)B a`.  Substitution reproduced the known feasible endpoint
row and supplied no marked contradiction.

## Cross-signature marginals remain feasible

Every outside triangle gives an eight-coordinate restricted polar signature
in the 81-word four-dimensional evaluation code of the canonical `M7g`
columns.  Exploratory integer marginal systems using row compositions and
the integral reflection Gram equations had feasible aggregates for every
form.  These aggregates omit intersection flags and graph completion, so no
solver output or feasibility object from that route is promoted.

## Local solver nonhits were not certificates

An exploratory Boolean model imposed selected-pair cross counts, exact
induced `A_U b=3b`, and local `lambda/mu` caps on the rank-three equality
branch.  Some labelled intersection patterns returned `UNSAT`, but no proof
certificate was emitted.  Those exits are discarded as claims.  Only two
positive models were retained, rewritten as solver-independent JSON, and
checked directly.

## Four linear relations are not four tensor relations

The canonical eight-column linear relation code has four projective
weight-eight words.  Only one has vanishing signed second moment and is the
endpoint tensor relation.  Treating all four as interchangeable would be a
false strengthening.  The exact checker explicitly separates them.

## No 99-vertex search

No graph completion, automorphism restriction, SAT nonexistence search, or
99-vertex enumeration was performed.  The finite domains are 27 forms,
`2^8` or `2^12` marked intersection subsets, and two positive local
certificate replays.
