# Protocol

## Scope

Extract pointwise block-codegree profiles and finite-field code structure
from the triangle incidence reformulation.

## Checks

1. Count disjoint blocks, boundary incidences, and sector matchings
   pointwise.
2. Preserve unordered-pair factors in the global distribution.
3. identify `N2` with the existing six-vertex `N3` motif.
4. prove the clique-size bound combinatorially rather than assuming graph
   transitivity or association-scheme closure.
5. derive the ternary identities before using characteristic multiplicities.
6. distinguish `rank(B*B^T)` from `rank(B)`.
7. label every star-complement or code classification as unexecuted.

## Computation boundary

This wave is paper-only because host memory was below the user's floor.
Future finite-field or star-complement work must start above 18 percent free
RAM, stop before 15 percent, and receive an independent exact verifier.
