# Boundaries and redirected routes

## Block codegree distribution alone

The exact pointwise profile at `P=0` is feasible and simply recovers
`n3=4158`. It supplies no strict inequality.

## Spectrum and clique size alone

The spectrum `18^1,7^54,0^44,(-3)^132` and the 99 maximum point-star
cliques are mutually consistent. No graph classification follows without
retaining the binary clique-incidence factor.

## Ternary rank alone

The exact Gram rank 55 only bounds the ternary row-code rank between 55 and
98. This interval is not contradictory.

## Retained route

Classify a 99-vertex star complement for eigenvalue `-3` together with the
99 point-star rows, or combine the ternary code with the Wave 168
neighborhood-triple columns and their prism-free multiplicities. Any finite
search must emit a complete exact certificate.
