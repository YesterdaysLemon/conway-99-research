# Completeness proof for the even endpoint types

## 1. Frozen rank formula

For an edge-local partition with `e` even parts, Wave 42 independently
verified

```text
rank(K39) = (25-2e) + 2 rank(F) + rank(D),
rank(F) >= e,
```

where `D` is symmetric. Since Wave 42 also excludes ranks below 27, equality
at 27 is possible exactly in the two cases

```text
(A) rank(F)=e   and rank(D)=2,
(B) rank(F)=e+1 and rank(D)=0.
```

If `rank(F)>=e+2`, the displayed formula already gives rank at least 29.

At the prism-free endpoint, the cross matching between the second and third
fibres is a derangement: a fixed coordinate, together with the two normalized
cross edges through the first fibre, is exactly a triangle in the 36-point
core and hence a triangular prism with the base triangle. The permitted
edge-local partitions are `222`, `24`, `33`, and `6`.

## 2. Generated-subspace cover for `222` and `24`

The projected columns of `F` are selected from the frozen 144-entry signature
table. If twelve selected columns span a space of dimension at most `r`, then
that space is generated by at most `r` observed projective lines. Therefore
enumerating every `r`-tuple of observed lines, reducing it to canonical row
space, and deduplicating covers every possible rank-at-most-`r` assignment.

For every generated space, the checker deletes diagonal assignments and
enumerates every supported bipartite perfect matching. Direct rank checks
then retain exactly:

```text
type 222, r=4: 332 derangements, all of rank 4;
type 24,  r=3: 1352 derangements, all of rank 3.
```

In particular there is no endpoint derangement at the minimum ranks three
and two, so mechanism (A) is absent for these types. For every retained
mechanism-(B) derangement, all 10,395 labelled perfect matchings `R` are
projected onto the exact canonical right kernel. Zero residual is literal
matrix equality. The 3,451,140 and 14,054,040 explicit pairs have zero hits.

No graph automorphism or orbit quotient is used.

## 3. Type `6`, minimum border rank

The verified complete minimum-border stream has 2,592 labelled
permutations, exactly 288 of which are derangements. Each is paired with all
10,395 labelled `R`.

For every symmetric residual the checker tests every `3 x 3` minor, not only
principal minors. A matrix has rank at most two if and only if all such
minors vanish. This is important because a direct sum of two hyperbolic
planes has rank four while all its principal `3 x 3` minors vanish.

All 2,993,760 residuals have rank above two, excluding mechanism (A).

## 4. Type `6`, one-extra border rank

The type-`6` signatures lie on six projective lines spanning dimension two.
Every nonminimum `F` therefore has rank exactly two. Mechanism (B) asks
whether the residual can vanish on its ten-dimensional right kernel.

Coordinate zero is the first pivot. For every rank-two permutation there is a
unique first later coordinate `q` on a different signature line. The checker
enumerates:

1. the images of coordinates zero and `q`, with derangement and
   all-different conditions;
2. the complete perfect-matching alternatives for their mates: either the
   pivots are mates, or they have an ordered pair of distinct mates among the
   remaining ten coordinates;
3. every remaining image satisfying the exact diagonal kernel-form
   equations; and
4. every all-different assignment satisfying the off-diagonal equations.

For a free coordinate `i`, write its signature as

```text
f_i = a_i f_0 + b_i f_q
```

and put

```text
z_i = e_i - a_i e_0 - b_i e_q.
```

The residual-zero equations are exactly

```text
z_i^T (W_R-T) z_i = 0,
z_i^T (W_R-T) z_j = 0.
```

The first equation gives a unary image domain. Once the two pivot mate
branches are fixed, the second uniquely requires `W_R(i,j)` to be either
`6` (mates) or `1` (nonmates); any other field value rejects the pair.
Degree one at every unmatched free coordinate reconstructs a unique complete
matching at a leaf.

Thus every labelled type-`6` rank-two permutation and every labelled
matching follows exactly one canonical pivot/mate branch. The exhaustive
search records:

```text
pivot-image branches: 1014
pivot-mate branches:  92274
unary-surviving:        488
backtrack nodes:       1058
complete leaves:          0.
```

Mechanism (B) is excluded.

## 5. Scoped conclusion and combination wall

The three even endpoint types have local rank at least 28. This package does
not cover the all-odd type `33` and therefore does not self-certify a
universal endpoint theorem.

The separate type-`33` discovery package uses a nonsingular principal
`2 x 2` pivot for every symmetric rank-two residual and reports zero leaves.
If an independent verifier accepts both packages, the four endpoint types
are exhausted and principal-block monotonicity gives

```text
n3=4158 => rank_F7(M)>=28.
```

The ceiling 44 remains compatible, so this is not an endpoint contradiction.
