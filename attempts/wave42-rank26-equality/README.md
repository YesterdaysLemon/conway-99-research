# Wave 42 rank-26 equality discovery

This package classifies equality in the verified Wave 41 bound

```text
rank_F7(K39) >= 26
```

for all eleven edge-local partition types. It starts from the frozen Wave 41
Schur decomposition and asks exactly whether the remaining symmetric residual
can have rank one.

The seven even-part types are covered by complete labelled enumeration of
every minimum-border permutation and all 10,395 third-fibre matchings. The
four all-odd types are covered by an exact pivot CSP that implicitly
enumerates all `12!` border permutations for every labelled third-fibre
matching. No automorphism of a completed graph is assumed.

The discovery result is:

| family | types | labelled minimum-`F`/`R` pairs | rank-one residuals |
| --- | ---: | ---: | ---: |
| even-part | 7 | 1,714,426,560 explicit | 0 |
| all-odd | 4 | 19,916,886,528,000 implicit CSP coverage | 0 |
| total | 11 | 19,918,600,954,560 | 0 |

The composed result has SHA-256
`94473b4c9f35184376765f76ab16646956222112836f49bcb22e950142a863a1`.

See `proof.md` for the completeness argument, `failed-routes.md` for the
discarded approaches, and the atomic `partial-*.json` files for machine
results.

The strongest possible output of this discovery lane is the candidate

```text
rank_F7(K39) >= 27
rank_F7(M) >= 27
```

It must not be promoted to `VERIFIED` by this package. It does not construct
a Conway graph, exclude `n3=4158`, improve `n3<=4158`, or establish novelty.

## Reproduce

Each atomic result can be regenerated byte for byte:

```powershell
$parts = @(
  '1+1+1+1+1+1', '2+1+1+1+1', '2+2+1+1', '2+2+2',
  '3+1+1+1', '3+2+1', '3+3', '4+1+1', '4+2', '5+1', '6'
)
foreach ($part in $parts) {
  .\.venv\Scripts\python.exe -B `
    attempts\wave42-rank26-equality\exact_check.py `
    --verify "attempts\wave42-rank26-equality\partial-$part.json"
}
```

Then verify the composition, tests, and package manifest:

```powershell
.\.venv\Scripts\python.exe -B `
  attempts\wave42-rank26-equality\compose_results.py `
  --verify attempts\wave42-rank26-equality\exact-results.json

.\.venv\Scripts\python.exe -B -m unittest discover `
  -s attempts\wave42-rank26-equality -p "test_*.py" -v

.\.venv\Scripts\python.exe -B `
  attempts\wave42-rank26-equality\manifest_check.py
```

The all-odd atomic replays use the exact implicit CSP and do not loop over
trillions of dense matrices.
