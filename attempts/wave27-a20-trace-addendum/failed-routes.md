# Wave 27 `A20` trace addendum: failed routes and boundaries

## Determinant-only bound was too weak

The submitted root-tensor package used only determinant plus AM-GM on the
`A20` compression, obtaining the noncontradictory floor 24. That route was
correct but not sharp enough. The integral rank-one factorization of the
`A_n` Cartan matrix activates evenness and raises the `A20` floor to 42.

## The argument is not a nonorthogonal-subsystem theorem

The principal `Q_AA` block and complementary determinant argument require an
orthogonal integral decomposition of `S`. An embedded or glued `A20` root
subsystem need not supply those blocks, so it is not excluded here.

## Dropping evenness destroys the contradiction

For a merely integral positive-definite `Q`, each of the `n+1` vector norms
in the trace identity can be one. The resulting local floor `n+1` does not
exclude `A20` at global trace 60.

## The threshold is exact only for this estimate

The aggregate estimate is `n+46`. At `n=14` it equals 60, so this argument
alone is noncontradictory; `n>=15` is excluded. This does not assert that an
orthogonal `A14` summand is realizable.

## Endpoint and target boundary

Eliminating full orthogonal ADE root lattices, once the imported component
theorems verify, does not classify general rank-44 even scaled-dual lattices.
No graph or endpoint exclusion follows.
