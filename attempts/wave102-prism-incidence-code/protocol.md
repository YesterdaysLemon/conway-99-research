# Wave 102 protocol: rooted prism-incidence code

## Frozen target

For a hypothetical `srg(99,14,1,2)`, let `f_v` be the number of induced
triangular prisms containing vertex `v`, let `P` be the total number of
prisms, and let

```text
O = #{v : f_v is odd}.
```

Investigate graph-specific information about the full vector `f`, rather
than only `sum_v f_v=6P`.

## Routes

1. Express `f mod 2` through the vertex-triangle and triangle-prism
   incidence matrices.
2. Derive all universal binary-code and adjacency-polynomial consequences.
3. Retain the exact parity defect omitted by the scalar Wave 100 bound.
4. Exhaust the first nontrivial low-prism cases and identify any
   parity-cancelling motif.

## Claim boundary

- Discovery may label exact finite/algebraic consequences `DERIVED`.
- No discovery claim self-promotes to `VERIFIED`.
- A parameter-compatible local motif is not a full graph construction.
- No strict `n3` upper bound, graph nonexistence, or Conway-99 resolution is
  claimed without a separate proof.
- Literature novelty remains `UNKNOWN`.
