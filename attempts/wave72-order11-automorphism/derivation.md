# Exact derivation

## 1. Orbit arithmetic

Let `G` be an `srg(99,14,1,2)` and let `g` have permutation order exactly 11.
Write `F` for the fixed-vertex set and `f=|F|`.

Every orbit of the cyclic group generated by `g` has size 1 or 11.  Hence

```text
f = 0 (mod 11).
```

The case `f=99` would make `g` the identity permutation, whose order is 1,
not 11.

## 2. The graph induced by the fixed vertices

Let `H=G[F]`, and for `x in F` write `d_x` for its degree in `H`.

The 14-element neighbor set `N_G(x)` is invariant under `g`.  Its nonfixed
orbits have size 11, so

```text
d_x = 14 (mod 11),    0 <= d_x <= 14.
```

Therefore

```text
d_x in {3,14}.
```

Now take distinct fixed vertices `x,y`.  Their common-neighbor set is
invariant under `g`.  Its size is 1 when `x,y` are adjacent and 2 when they
are nonadjacent.  Because both sizes are less than 11, this invariant set
cannot contain a nontrivial orbit.  Thus every common neighbor of two fixed
vertices is itself fixed.

It follows that, inside `H`,

```text
|N_H(x) intersect N_H(y)| = 1 if x~y,
                              2 if x!~y.
```

Summing the row of `A_H^2` indexed by `x` now gives the exact two-step-walk
identity

```text
sum_(y~_H x) d_y
  = d_x + 1*d_x + 2*(f-1-d_x)
  = 2f-2.                                      (1)
```

The first `d_x` on the middle line is the diagonal entry
`(A_H^2)_(x,x)`.

## 3. Elimination of every positive fixed set

Suppose first that every fixed vertex has degree 14 in `H`.  Equation (1)
becomes

```text
14*14 = 2f-2,
```

so `f=99`, already excluded because `g` has order exactly 11.

Consequently, if `f>0`, some fixed vertex has degree 3.  Applying (1) to that
vertex gives

```text
2f-2 <= 3*14 = 42,
```

so `f<=22`.  Since `f` is a positive multiple of 11, only `f=11` and `f=22`
remain.

### Case `f=11`

A simple graph on 11 vertices has maximum degree 10, so degree 14 cannot
occur.  Every fixed vertex would have degree 3.  Equation (1) would then read

```text
3+3+3 = 20,
```

a contradiction.

### Case `f=22`

Partition `F` into

```text
L = {x : d_x=3},    R = {x : d_x=14}.
```

For `x in L`, equation (1) says that the degrees of its three neighbors sum
to 42.  Since every such degree is at most 14, all three neighbors lie in
`R`.

For `y in R`, let `t` be the number of its 14 neighbors that lie in `R`.
Equation (1) gives

```text
14t + 3(14-t) = 42,
```

so `11t=0` and `t=0`.  Thus all 14 neighbors of `y` lie in `L`.

Therefore `H` is bipartite between `L` and `R`, with degrees 3 on `L` and 14
on `R`.  Counting cross edges in both directions gives

```text
3|L| = 14|R|,    |L|+|R|=22.
```

Hence `66=17|R|`, impossible over the integers.  As a separate consistency
check, any edge of this bipartite graph would have no common neighbor in
`H`, contradicting the already proved fixed-pair value `lambda=1`.

The cases `f=11` and `f=22` are both impossible.  Thus `f=0`.

## 4. Conditional combination with Wave 69

A fixed-point-free action of a group of order 11 on 99 vertices has exactly
nine orbits, each of size 11.  It is therefore precisely a semiregular
order-11 action of the scope treated in Wave 69.

If an independent verifier certifies both:

1. the fixed-point theorem above, and
2. Wave 69's complete exclusion of the nine-orbit semiregular quotient,

then a hypothetical target has no automorphism of order 11.

If the target were vertex-transitive, orbit-stabilizer would make its
automorphism-group order divisible by 99, hence by 11.  Cauchy's theorem would
then supply an element of order 11, contradicting the preceding conditional
conclusion.  Thus the same verified combination would exclude
vertex-transitive realizations.

This does not exclude an asymmetric target and is not a solution of the
unrestricted Conway-99 problem.

## 5. Edge cases audited

- `f=0` is the theorem's conclusion, not an omitted branch.
- `f=99` is the identity action and is incompatible with order exactly 11.
- Nonfixed orbit sizes are 11 because 11 is prime.
- Fixed neighborhoods and fixed-pair common-neighbor sets are invariant
  because `g` fixes their defining vertices.
- No vertex-transitivity assumption occurs in Sections 1--3.
- No claim that a failed restricted symmetry search proves global
  nonexistence is made.
