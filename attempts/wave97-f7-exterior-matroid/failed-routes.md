# Wave 97 retained null routes

## Symmetric-square rank alone

Wave 51 already derived the rank-98 pure-square span and the weak floor
\(r\ge14\). Wave 97 does not recycle that floor as a new obstruction. It
upgrades the statement to the exact Schur equality
\[
R*R=\mathbf1^\perp
\]
and derives the full cube, but saturation means there is no missing
quadratic or cubic dimension from which to extract a stronger rank bound.

## Cayley--Bacharach terminology

The 99 quadratic Veronese images form a circuit, equivalently a
degree-two Cayley--Bacharach set. This is an exact reformulation of the
unique all-nonzero quadratic relation. It does not classify the original 99
points in \(\mathbf P^{27}(\mathbf F_7)\), and no characteristic-zero
classification theorem is imported as if it applied automatically over
\(\mathbf F_7\).

## Exterior square

The \([4851,378]_7\) self-orthogonal compound code passes the elementary
dimension bound by a wide margin. Its complete Smith form follows
functorially from the verified Smith form of \(S\). A compatible Smith
profile is necessary, not sufficient, and does not construct \(S\).

The exact distinguished weight 1,947 supplies 29,106 scalar-closed words,
but this is negligible compared with \(7^{378}\). No ordinary MacWilliams
overfill follows.

## Generalized Hamming weights

Five-column independence only gives
\[
j+5\le d_j(R^\perp)\le j+28.
\]
These intervals never cross. The forced short vector improves only the
first upper bound to 18, leaving
\[
6\le d_1(R^\perp)\le18.
\]

## Orthogonal embedding counts

There is one \(O^-(42,7)\)-orbit of the relevant \(O^-(16,7)\) subspaces.
This is a null result for abstract orthogonal geometry: all coordinate
weight information has been discarded. Norm-16 and norm-18 classes even
land in the same square-anisotropic projective orbit.
