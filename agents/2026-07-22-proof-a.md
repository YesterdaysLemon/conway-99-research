## Master residual identities

Let `B` be the unknown 84-by-84 residual adjacency matrix and `C` the fixed
14-by-84 endpoint-label incidence matrix. Then

```text
C B = 2 J - C - M C,
B^2 = 12 I - B + 2 J - C^T C.
```

For distinct residual labels `p,q`, with `t=|p intersection q|`, this gives

```text
common_B(p,q) = 2 - B[p,q] - t.
```

## Main pruning result

For any root-neighbor endpoint `a`, let `F_a` be the 12 residual labels
containing it. For a matched pair `a,mate(a)`, the partition

```text
F_a, F_mate(a), remaining 60 labels
```

is equitable with quotient matrix

```text
[1 1 10]
[1 1 10]
[2 2  8].
```

The first two induced graphs and the bipartite graph between them are all
perfect matchings. Their 24-vertex union is therefore a 2-factor. At each
vertex, its cycle alternates a same-side edge and a cross edge; returning to
the original side requires an even number of cross edges. Every component
length is consequently divisible by four.

This gives 11 possible cycle partitions for each of the seven root-matched
pairs. These partitions are coarse types, not scaffold-stabilizer orbits; one
canonical 24-vertex representative per type would not be a safe exhaustive
split. Literature novelty is unknown.

## Residual spectrum

The proposed and algebraically reproduced spectrum is

```text
12^1, 3^40, 0^7, (-2)^6, (-4)^30.
```

It follows from `C C^T = 11 I + J - M`, the action of `B` on `im(C^T)`, and
the polynomial `B^2+B-12I=0` on `ker(C)`. In particular, the residual graph
would be connected.
