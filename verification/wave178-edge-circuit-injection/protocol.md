# Verification protocol

1. Treat all Wave 178 prose and executable results as untrusted.
2. Validate all discovery inputs and package entries.
3. Prove that a minimal dependent sub-support meets both outer stars.
4. Attack support multiplicity separately for shared and disjoint edge
   endpoints, using `lambda=1` only where an adjacent pair is established.
5. Pass from distinct circuit supports to projective relation classes using
   uniqueness of a circuit relation up to scalar.
6. Account explicitly for the two nonzero representatives over `F_3`.
7. Reconstruct the four local Gram kernels from the periodic recurrence,
   independently of discovery row reduction.
8. Use Gram kernels only as supersets of true relation kernels.
9. Perform no graph, code, SAT, configuration, or isomorphism search.
10. Preserve endpoint and global-existence status as `UNKNOWN`.
