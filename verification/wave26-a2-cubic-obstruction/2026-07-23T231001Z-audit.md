## 2. Exact premises and the tight-frame gate

Use the row convention

```text
X in Z^(231 x 44),
x_i = transpose of row i,
G = X^T X,
S = 21 G^-1,
M = X S X^T,
W = M o M,
Q = X^T W X.
```

The identity `M=X S X^T` alone is not enough. The proof actively uses the
tight-frame relation

```text
sum_i x_i x_i^T = X^T X = G = 21 S^-1
```

and the row norms

```text
x_i^T S x_i = M_ii = 4.
```

The independent hostile control retains integral norm-four full-rank rows and
`M 1=0` but drops the tight frame; antipodal pairs then give
`tr(A2 Q_AA)=0`. It also violates the public off-diagonal alphabet. This
confirms that the frame/projector package, not the displayed factorization in
isolation, carries the theorem.

## 3. Ordered-tensor Schur factorization

Let `Z` have row `x_i tensor x_i`. With the full ordered tensor-square metric,

```text
W_ij
 = (x_i^T S x_j)^2
 = <x_i tensor x_i, x_j tensor x_j>_(S tensor S),

W = Z (S tensor S) Z^T.
```

Putting `C=Z^T X` gives the exact coordinate factorization

```text
Q = C^T (S tensor S) C.
```

Suppose the displayed scaled-dual basis has

```text
S = A direct_sum R,  A=A2,
x_i=(a_i,u_i).
```

Then direct index expansion gives

```text
tr(A Q_AA)
 = || sum_i a_i tensor x_i tensor x_i ||^2_(A tensor S tensor S).
```

The four target subspaces

```text
A tensor A tensor A,
A tensor A tensor R,
A tensor R tensor A,
A tensor R tensor R
```

are mutually orthogonal. Therefore

```text
tr(A Q_AA)
 = ||T_AAA||^2 + ||T_AAR||^2 + ||T_ARA||^2 + ||T_ARR||^2
 = ||T_AAA||^2 + 2||T_AAR||^2 + ||T_ARR||^2
 >= ||T_AAA||^2.
```

Thus arbitrary cross-block components of `Q` cannot lower the compression.
In the inherited symmetric-square metric, the normalized mixed tensor is
`(a tensor u + u tensor a)/sqrt(2)`, so its coefficient is `sqrt(2)`.
The ordered calculation above retains the same factor as the explicit two
mixed blocks and avoids any normalization ambiguity.

The checker reproduces this factorization on an independent synthetic matrix
with nonzero mixed blocks; it does not merely compare formula strings.


## 7. Basis, orientation, and compression conventions

For an integral congruence placing the selected summand in displayed form,
the contragredient row-coordinate change obeys

```text
S' = P^T S P,
X' = X P^-T,
Q' = P^-1 Q P^-T.
```

Hence

```text
tr(S'_AA Q'_AA)=tr(S_AA Q_AA)
```

for an internal basis change of the transported summand. The literal
upper-left block is not invariant under an arbitrary basis change mixing the
summand with its complement; the summand itself must be transported. The
independent checker tests the displayed covariance and confirms that `M`
does not change.

The discovery report sometimes calls the object a “231-column” realization,
but its displayed and correct algebra has `X` of shape `231 x 44`; the 231
objects are rows. This is a terminology defect only, not a matrix-orientation
error in the proof.
