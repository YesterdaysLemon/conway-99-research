# Wave 26 literature audit: inspected sources

## Classification key

- **D**: direct match to the parameter-specific claim or the stated `A2`
  exclusion.
- **N**: near-direct theorem whose hypotheses visibly cover the target.
- **M**: relevant general machinery.
- **B**: background terminology.

No inspected source reached class D or N. “Does not supply” below means only
that the inspected source does not state the target result; it is not a claim
about everything that could be derived from that source.

## Citation-chase result

strongly-regular-graph, and Hadamard-Gram sources produced additional
machinery/background items but no class D or N source. The main routed items
retained above are S02, S08, S10, S12, and S14. Unrelated Schur-complement
numerical-linear-algebra results and unrelated uses of `A2`, `231`, or “lattice”
were excluded as keyword collisions.
