# Independent audit protocol

Role: verifier.

## Frozen scope

Audit the sealed Wave 127 and Wave 129 rank-28, discriminant-16, level-7
index-10/index-70 Jacobi finite relaxations.  Exact feasibility may be
certified only for a rational 239-coordinate vector that satisfies every
original equality and inequality.

## Independence rules

- Freeze and preinspect both manifests before reading discovery prose.
- Import no discovery code or verification routine.
- Reconstruct modular dimensions and Eisenstein-product ranks independently.
- Derive the Fricke block factor independently.
- Treat sealed Fourier columns as inputs, checking their normalizations,
  symmetry, block sizes, cross-cutoff truncations, and Fricke boundary values.
- Rebuild and evaluate every unreduced finite constraint row using exact
  `Fraction` arithmetic.
- A floating point, failed recovery, or solver exit status is not a
  certificate.

## Status wall

Exact finite feasibility does not establish a complete theta series,
lattice, graph, rank realizability, or Conway-99.  Cutoff 28 remains
`UNKNOWN` absent either a rational feasible point or an exact Farkas
certificate.
