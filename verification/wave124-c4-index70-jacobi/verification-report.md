## 2. Primitive C4 marking

Let an induced four-cycle be ordered cyclically and put

```text
epsilon = (1,-1,1,-1),        d_C = sum_i epsilon_i u_i.
```

Because the signs sum to zero, `d_C` lies in `M`, hence in `L`.  The
four-by-four Gram matrix sends `epsilon` to `5 epsilon`, so

```text
(d_C,d_C) = 20.
```

If `d_C=k e` in the even lattice `L` for an integer `k>1`, then
`20/k^2` would have to be a positive even integer.  No such `k` exists, so
`d_C` is primitive.

The verifier also supplied an explicit divisibility-one argument on the L
side.  An induced C4 sends `4(14-2)=48` edges to outside vertices.  If
`k_v` counts the neighbours of an outside vertex on the cycle, the SRG
common-neighbour parameters give

```text
sum_v binom(k_v,2) = 4.
```

Thus some outside vertex has `k_v=1`; otherwise
`sum k_v <= 2 sum binom(k_v,2)=8`.  Its frame vector pairs `+1` or `-1`
with `d_C`.  Hence `div_L(d_C)=1`.

Now put `b_C=sqrt(7)d_C` in `K=sqrt(7)L*`.  Then

```text
(b_C,b_C)=140,   index_K=70,   index_L=10.
```

For `sqrt(7)y in K`,

```text
<sqrt(7)y,b_C> = 7<y,d_C>.
```

Primitivity of `d_C` means the pairings with `L*` have gcd one, so the
K-side divisibility is exactly seven.  This reduces the Wave 116 indices
`630/90` by a factor of nine.
