# Wave 131 verifier protocol

Role: independent verifier.

## Frozen target

Audit the conditional binary-code deductions and the sealed rational
ordinary MacWilliams witness.  The imported minimum-eight code bounds are
treated as frozen prerequisites.

## Independence

- Freeze and preinspect the discovery manifest before reading the package.
- Import no discovery checker.
- Rederive the LCD and symplectic facts from symmetry and idempotence.
- Recount every graph-subset type through size three.
- Recompute all weights and aggregate distributions.
- Parse every enumerator coefficient as an exact `Fraction`.
- Evaluate both directions of all MacWilliams equations with an independent
  Krawtchouk implementation.
- Check sizes, distances, parity, complement symmetry, lower bounds,
  nonnegativity, and fractional coefficients.

## Status wall

An exact rational enumerator is not an integral enumerator or code.  An
integral enumerator would not certify LCD or the distinguished graph-row
Gram matrices.  Timeout is not evidence.  No code, adjacency matrix, graph,
rank exclusion, Conway-99 result, or novelty claim may be promoted.
