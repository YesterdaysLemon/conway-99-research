# Independent verification protocol

1. Freeze the proof-B report, its checker as inert source, and all six direct
   mathematical inputs by exact SHA-256.
2. Do not import or execute the discovery checker while deriving the result.
3. Treat every listed mass as a rational projective scalar-pair mass. Never
   promote it to an integer word count, linear code, or point configuration.
4. Reconstruct all 232 ordinary ternary Krawtchouk coefficients exactly and
   check both `B_j>=0` and `B_j>=A_j`.
5. Reconstruct the complete ternary transform over
   `Z[omega]/(omega^2+omega+1)` and use exact cyclotomic traces.
6. Stop the complete transform at total degree seven: certify
   nonnegativity through six and record the first negative coefficient at
   seven. Perform no floating degree-nine work.
7. Enumerate projective representatives of the explicit parabolic form only
   to check class sizes and canonical one-, two-, and three-point complement
   types; do not search for a 231-point set.
8. Recompute typed factorial moments and every integral triple-census
   incidence equation exactly.
9. Compare with the frozen discovery output only after the clean-room
   reconstruction is complete.
10. Report a relaxation boundary, never code or endpoint existence.
