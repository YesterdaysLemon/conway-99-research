# Independent verification protocol

Checks:

1. reconstruct all three pointwise double counts;
2. audit unordered global multiplicities and the `N2` motif;
3. prove clique size seven from linear triple incidence;
4. reduce the SRG algebra over `F_3`;
5. account for possible Jordan blocks before taking ranks;
6. distinguish Gram rank from incidence-matrix rank; and
7. retain the absence of any new numerical bound.

The audit is paper-only. No computation ran below the host memory floor.
