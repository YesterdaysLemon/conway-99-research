# Failed routes and nonpromotion wall

## Comparing a live checkpoint

The first post-freeze comparison opened `cutting-plane.json` after it had
reported 17 cuts and 15 witnesses. A concurrent continuation then changed it
to `RUNNING` with additional records. That comparison was discarded. No hash
or conclusion from the mutable file is used.

Verification resumed only on the immutable checkpoint-v1 files and their
sealed manifest.

## Optional graph library

The first clean implementation draft expected NetworkX solely for an
unlabelled graph census, but NetworkX was not installed in the project
environment. Before any discovery inspection, the implementation was changed
to enumerate every labelled mask through order seven and quotient full
permutation orbits itself. This made the construction more independent and
introduced no extra package requirement.

## Floating spectra

Tiny negative floating eigenvalues occur even for exact PSD Petersen and
Clebsch controls. They are numerical roundoff, not counterexamples. All
promotion decisions use exact outer products, rational LDL, or integer
quadratic values.

## Stored witness refutation as endpoint refutation

The negative directions exclude two aggregate vectors only. A different
seven-class vector may satisfy the same 170 linear equations and all retained
PSD cuts. Treating either refutation as an endpoint contradiction would be
invalid.

## Finite cutting loop as complete search

Checkpoint v1 contains 17 valid cuts and 15 exact witnesses. Its next QF_LIA
solve timed out and returned `unknown`. Solver-unknown is not proof, and a
finite adaptively chosen set of directions does not impose the full PSD cone.

Therefore the endpoint, strict upper bound, and Conway-99 remain `UNKNOWN`.
