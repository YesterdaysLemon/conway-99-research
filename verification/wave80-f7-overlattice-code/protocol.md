# Wave 80 clean-room verification protocol

1. Freeze every discovery path, byte length, and SHA-256 before inspecting
   the mathematical derivation or executing discovery code.
2. Validate the advertised discovery manifest as a byte-level seal.
3. Import only the independently verified Wave 66 and Wave 71 results.
4. Reconstruct the evaluation map, its bilinear form, radical, and hull from
   the marked-vector spanning argument.
5. Derive every finite orthogonal-space type from determinant square classes,
   including the ambient quotient and orthogonal complement.
6. Independently enumerate every labelled Seidel sign pattern through order
   five and test the full 99-coordinate outside equations.
7. Check the Wave 71 short-vector images and self-dots directly from the
   marked frame.
8. Generate a canonical independent result before replaying discovery tests
   or comparing selected discovery fields.
9. Preserve `UNKNOWN` for graph existence, Conway-99, endpoint exclusion, and
   literature novelty.

The verifier does not edit the discovery package, central documentation, or
Git state.
