# Wave 102 verifier protocol

1. Freeze the SHA-256 hash of the discovery package manifest without
   opening the derivation or archived result.
2. Reconstruct the parity-defect floor identity from the verified Wave 100
   rootwise inequality.
3. Enumerate all labelled two-prism overlaps and all three-six-set incidence
   profiles with parity weight at most two.
4. Apply only necessary `lambda=1` and `mu=2` common-neighbor caps; never
   treat a cap-compatible partial graph as globally extendible.
5. Reconstruct the binary triangle-incidence algebra, ranks, code-dimension
   ranges, and triangle-check weight restrictions.
6. Verify the nine-vertex rook branch and the 12-vertex
   `C4 square K3` parity-null control independently.
7. Emit and hash the pre-comparison independent result.
8. Only after the independent freeze, inspect and rehash the discovery
   package, compare claims, run both test suites, and record corrections.

Promotion rule: the verifier may certify only the scoped conditional
theorems.  No local motif, finite census, or code-dimension range can be
promoted to graph existence, graph nonexistence, or a Conway-99 resolution.
