## 3. Arbitrary-border rank lemma

Let `S` be any symmetric matrix over `F_7`, let the columns of `H` form a
basis of `ker(S)`, and let `U,W` be arbitrary compatible matrices. Then

```text
rank [ S    U ] >= rank(S) + 2 rank(H^T U).       (1)
     [ U^T  W ]
```

No condition on `W` is needed.

To prove this, choose a basis whose final vectors are the columns of `H`.
Congruence transforms `S` into

```text
[ D  0 ]
[ 0  0 ],
```

where `D` is invertible of order `rank(S)`. Eliminating the part of `U`
beside `D` leaves `D` as a direct summand and a matrix

```text
[ 0    Q  ],   Q=H^T U.
[ Q^T  W' ]
```

Put `t=rank(Q)`. If `(a,b)` belongs to this latter matrix's kernel, then
`Qb=0`, leaving at most `dim(b)-t` choices for `b`; for any such `b`, the
equation `Q^T a=-W'b` leaves at most `dim(a)-t` choices for `a`. Its
nullity is therefore at most its order minus `2t`, proving (1).

For the graph, the 39-by-39 principal block on `L union Z` has exactly this
form. Consequently, if the twelve chosen border signatures have rank `t`,
the global transported matrix has rank at least

```text

```
