# Failed routes and retained limitations

## Initial inventory path formatter

The first read-only inventory command used
`System.IO.Path.GetRelativePath`, which is unavailable in the installed
PowerShell/.NET runtime.  It emitted hashes without usable paths and was not
accepted as the freeze.  Before inspecting any discovery content, the
inventory was rerun using a workspace-prefix substring and the complete
17-path result was saved in `discovery-input-freeze.sha256`.

## Canonical search as certificate

Canonical augmentation can be fast but is vulnerable to an incorrect
symmetry rule.  It is not used as the proof basis.  The independent
label-complete tree enumerates all assignments within equal-diagonal classes
and applies no canonical rejection.

## Direct voltage search

No voltage SAT search is needed or claimed.  Any cyclic 11-cover has a
frequency-zero quotient.  The complete quotient obstruction empties the lift
space before voltage variables are introduced.

## Cayley scope

The Fourier proof applies to Cayley graphs, not arbitrary 99-vertex graphs.
The group-theoretic fact that all groups of order 99 are abelian does not make
every graph on 99 vertices Cayley.

## Global scope

Excluding order-11 automorphisms and vertex-transitive realizations does not
exclude asymmetric graphs or graphs with automorphism group order not
divisible by 11.  The unrestricted problem remains `UNKNOWN`.
