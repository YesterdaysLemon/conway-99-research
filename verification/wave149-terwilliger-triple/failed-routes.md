# Failed routes and retained limits

1. **First Gram/PSD obstruction.** This route does not force a prism. The
   explicit zero-prism matching witness yields an entrywise admissible,
   positive-semidefinite forced Gram matrix of rank 32.
2. **Rank obstruction at 60 columns.** This also fails: rank 32 is below the
   available factor dimension 60.
3. **Matrix feasibility as graph realization.** Rejected. A positive
   semidefinite integer matrix need not admit a binary incidence factor with
   the required column sums.
4. **Local witness as a Conway-99 resolution.** Rejected. No residual
   adjacency block or cross-root compatibility is supplied.

The next honest obstruction must impose stronger discrete incidence
realizability, residual-block compatibility, or compatibility among several
overlapping root configurations.
