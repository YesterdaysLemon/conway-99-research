# Verification protocol

1. Treat every Wave 176 formula and program result as untrusted.
2. Check the discovery package and all recursively frozen inputs before
   using them.
3. Reconstruct the seven-column simplex projector from its Gram matrix and
   sole coefficient relation.
4. Derive the trace Gram and the `65`-dimensional target using self-adjoint
   endomorphisms, without assuming that projectors commute.
5. Derive the adjacent-star cross graph directly from
   `srg(99,14,1,2)` and `P=0`; perform no graph or code search.
6. Obtain the four Gram ranks independently from the periodic
   second-difference equation on each cycle component.
7. Distinguish the coefficient-relation kernel from the Gram kernel.  Use
   the radical inequality before identifying them.
8. Check support distributions only when equality of those kernels has
   been proved.
9. Run a clean-room exact checker, then replay the discovery checker and
   its focused tests.
10. Veto endpoint exclusion, an improved `n3` bound, a graph construction,
    external novelty, or a Conway-99 resolution.
