# Formal proof and proof-certificate work

Store theorem-prover developments, verified encodings, and compact proof
checkers here. Generated proof artifacts may be kept externally when large,
provided a versioned manifest, retrieval URL, and SHA-256 digest are committed.

`opb-calibration/` contains canonical LF pseudo-Boolean formulas, raw VeriPB 3
proofs, and elaborated proofs for the small pair-count 2 (SAT) and pair-count 3
(UNSAT) controls. Exact replay commands, tool identities, and hashes are in
`verification/2026-07-22-veripb-calibration.md`. These fixtures calibrate the
pipeline only; they do not cover a target branch.
